# FitBuddy - AI Fitness Plan Generator using Gemini Model 🏋️‍♂️🥗

FitBuddy is an intelligent fitness and diet planning application powered by Google's Gemini AI. It creates personalized workout regimes and nutrition guides tailored to individual user goals, fitness levels, and dietary preferences.

## 🌟 Key Features
- **Personalized Workout Plans:** Tailored exercise routines based on user goals (e.g., weight loss, muscle gain, fitness).
- **Customized Meal & Nutrition Plans:** AI-generated daily calorie requirements and food recommendations.
- **Smart Gemini AI Integration:** Leverages Google Gemini Model for intelligent recommendations.
- **Easy User Inputs:** Quick input forms for age, weight, height, activity level, and fitness objectives.

## 🛠️ Tech Stack
- **AI Model:** Google Gemini API
- **Technology:** Generative AI, Python
- **Repository:** Project Files & Specification Documents

## 📌 Project Overview
FitBuddy aims to make personal fitness guidance accessible and smart by using modern Generative AI techniques to automate fitness consultation.
